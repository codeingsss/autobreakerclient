Squeeze every frame out of Minecraft.

A free, 100% open-source Fabric client mod — performance presets, quality-of-life modules, motion blur and a fully custom orange-themed settings menu, all in one jar.

GPL-3.0 Fabric Minecraft 1.21.11

What's inside

Extreme Performance

One switch that disables vsync, particles, clouds, shadows and view bobbing, plus a render-distance slider — for when you just want frames.

Quality of Life

Zoom, Full Bright, Auto GG and more — small conveniences built on vanilla's own options, nothing closed-source.

HUD Editor

Drag every HUD element — watermark, FPS, ping, CPS, clock, armor, server address — anywhere on screen, enabled or not.

Motion Blur

Frame-accumulation blur on fast camera movement, built on vanilla's own post-effect pipeline — no shader pack required.

Profiles & Sharing

Save named profiles and auto-load one per server address, or export your whole setup as a single share code for someone else to import — no account, no backend.

Fully Open Source

GPL-3.0, no telemetry, no account, no paywall. Read every line, build it yourself, send a PR.

Install

  1. Install Fabric Loader for Minecraft 1.21.11.
  2. Grab Fabric API and Fabric Language Kotlin.
  3. Download the latest AutoBreaker release and drop the jar into your mods folder.
  4. Launch the game, press Right Shift to open the menu.
